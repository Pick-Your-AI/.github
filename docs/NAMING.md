# Organization naming register

Approved naming alignment: 2026-10-29. This register defines names and links; GitHub remains authoritative for current membership, grants and issue ownership. Historical receipts and frozen snapshots retain their original names.

## Conventions

- Product name in prose: **Pick Your AI**. GitHub organization: `Pick-Your-AI`. Public domain: `pickyour.ai`.
- Project title: `Pick Your AI — <Category> — <Area>`.
- Area team: `<Area>`. Specialist team: `<Area> - <Specialty>`. Lead team: `Lead Maintainers - <Area>`.
- Repository names remain lowercase `pick-your-ai-<purpose>`. `.github` and the private `internal-discussion` repository are intentional role-specific exceptions.
- Category labels classify Projects; they do not reparent GitHub teams. Catalog Pipeline and Funding remain under Research, and Education remains under Organization Maintainers.
- Functional Team Workstream values may differ from team names as documented by each Project. Keep existing classifications, issue identities and assignments.

## Maintenance and boundaries

Use [#17](https://github.com/Pick-Your-AI/.github/issues/17) for the existing live-directory, routing and documentation work. This static naming register does not implement automatic synchronization or complete that issue. [#18](https://github.com/Pick-Your-AI/.github/issues/18) records accepted team-management delegation and interim coverage. A lead-team name does not establish Admin access or accepted operational ownership.

Update this register and affected current links when a naming change is approved. Preserve repository names, frozen evidence, independent review requirements and existing governance exceptions.
