# Support and decisions

For a public governance question, search existing [issues](https://github.com/Pick-Your-AI/.github/issues) first and add evidence to the matching issue. Follow [the escalation guide](docs/governance/ESCALATION.md) to resolve the current responsible role rather than copying a personal contact list.

For project-specific work, begin in that repository and preserve its support, security and contribution instructions. A public issue is not a private disclosure channel. Do not post credentials, private membership data, personal/customer records or vulnerability details in governance issues. This page does not create a new private inbox or certify a receiving route.

The route is repository team → repository maintainer → repository lead maintainer → applicable parent teams → CompleteDotTech. Unfilled and unresolved roles remain visible; team management and access alone are not accepted operational ownership.

See [current organization operation and mapping](docs/ORGANIZATION.md) for the shared directory, refresh status, unresolved responsibility and proposed mapping changes. Published artifact observations and latest refresh checks are separate timestamps.
